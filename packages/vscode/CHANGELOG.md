# Changelog

## 0.2.0

Rebuilt from scratch on the new MarkUP core.

- Language server: diagnostics with quick fixes, completion for components, attributes, values, chart data keys, anchors, footnotes and code languages; hover documentation; outline; folding; go to definition and references; document links; semantic highlighting.
- Live preview with bidirectional scroll sync, theme following, double-click to edit and safe local images.
- Commands: Export to HTML, Insert Component, Show Component Reference, Restart Language Server.
- Plugins from `markup.config.json` in trusted workspaces.
